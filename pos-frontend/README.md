# POS Management System – Frontend

A modern and responsive frontend for a **Point of Sale (POS) Management System**, developed using **React and Vite**. The application provides an easy-to-use interface for managing companies, products, units, and other POS-related operations.

## 🚀 Technologies Used

* **React.js** – Frontend library
* **Vite** – Development and build tool
* **JavaScript 
* **HTML5**
* **CSS3**
* **React Router** – Application routing
* **Tailwind CSS** – UI styling
* **REST API** – Communication with the backend
* **Git & GitHub** – Version control

## ✨ Features

* User-friendly POS dashboard
* Company management
* Product management
* Unit management
* Add, update, view, and delete records
* Form validation
* Responsive user interface
* Integration with Spring Boot REST APIs
* Dynamic data display from the backend
* API-based CRUD operations

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/taniya-232/POS-Management-System.git
```

### 2. Navigate to the frontend directory

```bash
cd POS-Management-System/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

## 🔗 Backend Integration

The frontend communicates with the **Spring Boot backend** through REST APIs.

Backend:

```text
Spring Boot + MySQL
```

Frontend:

```text
React + Vite
```

Make sure the backend server is running before using features that require database access.
